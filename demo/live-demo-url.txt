NOT DEPLOYED — run locally using docs/setup-guide.md

To run the application locally, follow the setup instructions in docs/setup-guide.md.
The setup takes under 5 minutes on a machine with Python 3.10+.

Quick start:
  git clone https://github.com/Jigar-CS/bob-ai-hackathon-ABC.git
  cd bob-ai-hackathon-ABC
  python -m venv .venv
  source .venv/bin/activate      # Windows: .venv\Scripts\Activate.ps1
  pip install -e ".[dev]"
  uvicorn portpulse.main:app --reload

Then open: http://127.0.0.1:8000
